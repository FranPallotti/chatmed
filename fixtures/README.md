They are generated by `scripts/make_fixtures.py` (`uv run python scripts/make_fixtures.py`); do
not edit the PDFs by hand.

## CIOMS I-style forms (D12)

One synthetic case for tenant **acme**, subject **01001-004** of study ACM-101. The same subject
and event are in `db/seed/tenant_acme.sql` (`adsl` row `01001-004`, `adae` row with
`aeseq = 2`, start date 2026-06-12, drug withdrawn), so extracted facts can be joined to the
tenant database through `subject_id -> adsl.subjid`.

The layout follows the public CIOMS I form sections (I reaction, II suspect drug, III concomitant
drugs, IV manufacturer). Dates are written in ISO format (YYYY-MM-DD) so that the document text,

## Reproducibility check across platforms

`tests/test_parsing.py` regenerates the fixtures and compares them with the committed files:

- Digital fixtures: byte for byte (fpdf2 with a pinned creation date and built-in fonts).
- Image-only fixtures (`scanned_lab_report.pdf`, `mixed_report.pdf`, `cioms_initial_scanned.pdf`):
  the embedded raster and its compression can differ between Windows and Linux, so the bytes are
  not compared. Instead: same page count, the image-only pages have no text layer, and each page
  rendered at a fixed DPI in grayscale has the same size and a mean pixel difference below 1%.
